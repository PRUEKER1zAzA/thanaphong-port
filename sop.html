Statement of Purpose

เรียงความแสดงความจำนงในการศึกษาต่อ

สวัสดีครับท่านคณะกรรมการ คุณครู ที่เคารพผมชื่อ นายธนพงษ์ ขุนบำรุง กำลังศึกษาอยู่ในระดับชั้นปวช.3 สาขาวิชาเทคโนโลยีสารสนเทศ สาขางานการโปรแกรมคอมพิวเตอร์ เว็บ และอุปกรณ์เคลื่อนที่ ผมชอบคอมตั้งแต่เด็กเล่นแต่เกมทั้งวัน เป็นเด็กติดเกมคนนึง แรก ๆ ผมเห็นว่าภาษาเป็นทางเลือกที่น่าสนใจ ผมเลยลงเรียนศิลป์ภาษาตั้งแต่ม.1-ม.3 ไม่รู้ว่าตัวเองชอบอะไรกันแน่คิดว่าจะเรียนต่อดีไหมใน ม.4 ผมก็คิดว่าถ้าชอบเล่นเกมคอมพิวเตอร์ชอบเล่นคอมเล่นอินเตอร์เน็ตงั้นก็เรียนคอมดีกว่า เลยเข้ามาเรียนคอมพิวเตอร์โปรแกรมตอน ปวช.1 ที่วิทยาลัยเทคนิคหาดใหญ่ เข้ามาแรกๆ ก็คิดว่าน่าสอนเขียนโปรแกรมเบื้องต้น น่ ที่ไหนได้ครูเปิดทฤษฎีการวิเคราะห์ระบบงาน ทั้งการคำนวณนู้นนี่ เต็มไปหมดผมไม่ค่อยเก่งคณิตศาสตร์อยู่แล้ว คราวนี้แหละทำยังไง เลยพยามลองศึกษา ดูไปเรื่อย ๆ จนเข้าใจหลักการต่าง ๆ ถามตัวเองว่าไหวไหม อยากเรียนเองก็ต้องสู้ดิ เข้ามาแล้วอย่าให้พ่อแม่ผิดหวัง ผมก็พยามถามเพื่อนที่เข้าใจที่เก่งๆ ว่าทำยังไงอธิบายหน่อยจนเข้าใจบ้างแล้วก็เริ่มรู้สึกว่าอยากศึกษาเบื้องต้นมาก่อน ที่จะเรียนจริงๆ เพื่อให้เรียนรู้เร็วขึ้น เลยหาวิธีเรียนในยูทูป บางทีก็ถาม AI ให้อธิบายให้ฟัง

ที่ผ่านมาผมเรียนที่วิทยาลัย ก็ได้รับความรู้มานิดหน่อยไม่ได้ลึกมาก มีช่วงปิดเทอมช่วงนึงผมมีเวลาว่างเลยเริ่มศึกษาการทำหน้าเว็บแบบจริงจัง ผมไม่รู้ว่าควรเริ่มยังไงดีเลยศึกษาการทำหน้าบ้าน Font-end กับยูทูปช่องหนึ่งสอนการวางโครง HTML และ สอนเขียน CSS ลองศึกษาดูจนเข้าใจหลักการอะไรหลาย ๆ อย่าง จากนั้นผมก็เริ่มไปศึกษา Back-end ว่ามันคืออะไรจนไปเจอ PHP เข้าว่ามันนิยมทำ Web Sever เลยลองศึกษาดูก็เริ่มฝึกทำเว็บแอปแรก แอปแชท สร้างโดยการลอกจัดวางโครงตาม Instragram แล้วมาปรับแต่งเองทีหลัง แต่ผมคิดว่าเรียนผ่านยูทูปมันไม่ได้ เนื้อหาที่มันแน่นมากพอ โครงงานของผมอยู่ในในช่วงฝึกงานพอดีเลยทำระบบให้กับวิทยาลัยอาชีวศึกษาสงขลาเกี่ยวกับปัญหากล้องวงจรปิด ช่วยให้การทำงานมีความสะดวกรวดเร็ว เช่น การจัดหาเลขครุภัณฑ์ต้องตามดูว่าตัวไหน เพื่อส่งซ่อมก็สะดวกรวดเร็วมากยิ่งขึ้น เช็คสัญญาณการเชื่อมต่อของกล้องโดยการปิงไปหาเลข IP Adress ของกล้อง ตรวจสอบดูสถานะแบบเรียลไทม์ได้ตลอดเวลาลา ผมเลยคิดว่า Computer Science จะทำให้ผมได้เรียนเนื้อหาที่ลึกขึ้นกว่าที่ผมพยามหามาตลอด ได้เรียนต่อที่นี่ เป้าหมายผมคือ ถ้าเรียนจบจะเป็นคุณครูสอนให้นักเรียนรุ่นต่อๆ ไป ได้เข้าใจหลักการต่าง ๆ ผมก็เป็นคนนึงรู้สึกดีที่ได้ช่วยเหลือคนอื่น แบ่งปันความรู้ ถ่ายทอดออกไป มันทำให้ผมรู้สึกดีรู้สึกว่าได้รับความรู้เพิ่มเข้าไปเป็นการทบทวนตัวเองไปในตัว ไม่ว่าจะเป็นการเขียนโปรแกรม Full-stack development การออกแบบระบบ และการทำเซิร์ฟเวอร์ ระบบเครือข่าย ตลอดระยะเวลาที่ศึกษา ข้าพเจ้าได้ฝึกพัฒนาเว็บไซต์และเขียนโปรแกรมด้วยภาษา HTML, CSS, JavaScript และ Python ผลงานที่ข้าพเจ้าภาคภูมิใจคือการพัฒนาเว็บไซต์ Portfolio ของตนเอง ซึ่งได้ออกแบบหน้าตาเว็บไซต์ เขียนโค้ด และแก้ไขปัญหาที่เกิดขึ้นระหว่างการพัฒนาด้วยตนเอง ทำให้ข้าพเจ้าได้เรียนรู้การคิดอย่างเป็นระบบ การวิเคราะห์ปัญหา และการพัฒนางานให้มีประสิทธิภาพมากยิ่งขึ้น

ข้าพเจ้ามีความประสงค์เข้าศึกษาในหลักสูตรวิทยาศาสตรบัณฑิต สาขาวิชาเทคโนโลยีสารสนเทศและการสื่อสาร เพราะเชื่อว่าหลักสูตรจะช่วยเสริมความรู้ทั้งด้านการพัฒนาซอฟต์แวร์ การออกแบบระบบ และเทคโนโลยีสมัยใหม่ ซึ่งจะเป็นพื้นฐานสำคัญในการพัฒนาทักษะและต่อยอดความสามารถของข้าพเจ้า

ในอนาคต ข้าพเจ้าตั้งเป้าหมายที่จะเป็นนักพัฒนาซอฟต์แวร์ที่สามารถสร้างระบบและแอปพลิเคชันที่ตอบโจทย์การใช้งานจริง พร้อมทั้งพัฒนาความรู้ของตนเองอย่างต่อเนื่อง และนำความสามารถที่ได้รับจากการศึกษาไปสร้างประโยชน์ให้กับองค์กรและสังคม ข้าพเจ้าหวังเป็นอย่างยิ่งว่าจะได้รับโอกาสเข้าศึกษาในหลักสูตรนี้ เพื่อพัฒนาศักยภาพของตนเองและก้าวสู่การเป็นบุคลากรด้านเทคโนโลยีสารสนเทศที่มีคุณภาพในอนาคต
